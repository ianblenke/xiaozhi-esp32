# Build Configuration Commands

**Set the build target to ESP32S3:**

```bash
idf.py set-target esp32s3
```

**Open menuconfig:**

```bash
idf.py menuconfig
```

**Select the board:**

```
Xiaozhi Assistant -> Board Type -> Movecall Moji Xiaozhi AI Derivative Edition
```


**Build:**

```bash
idf.py build
```
