# jiuchuan-xiaozhi-sound
Jiuchuan Technology Xiaozhi AI Speaker

## 🛠️ Build Guide
**Development Environment**: ESP-IDF v5.4.1

### Build Steps:
> ⚠️ **Note**: If accessing online libraries fails during the build process, try toggling the accelerator status or modify the [idf_component.yml] file to use a domestic mirror source.

1. Open the project folder using VSCode;
2. Clean the project (Clean Project);
3. Set the ESP-IDF version to `v5.4.1`;
4. Click the prompt at the bottom right of VSCode to generate the [compile_commands.json] file;
5. Set the target device to `[esp32s3] -> [JTAG]`;
6. Open the **SDK Configuration Editor**;
7. Set **Board Type** to **Jiuchuan Technology**;
8. Save the configuration and start building.

## 🔌 Flashing Steps
1. Connect the computer to the speaker using a data cable;
2. Turn off the device power, then press and hold the power button;
3. Select the corresponding serial port (COM Port) in the flashing tool;
4. Click the flash button and select UART mode;
5. Do not release the power button until flashing is complete.


## Pin Configuration
- 1-9:
  - 1. DAT2     : NC
  - 2. CD/DAT3  : Chip select, active low. (Unknown)
  - 3. CMD      : IO48 (Command/Response Line), the host sends commands and data to the TF card through this line
  - 4. VDD      : Power supply
  - 5. CLX      : IO47 (Clock), generated by the host, synchronizes data communication
  - 6. VSS      : GND
  - 7. DAT0     : IO21, SPI_MISO, the TF card returns responses and data to the host through this line
  - 8. DAT1     : NC
