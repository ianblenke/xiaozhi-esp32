# Usage Instructions


**Build**

```bash
python ./scripts/release.py m5stack-core-s3
```

For manual compilation, please refer to `m5stack-core-s3/config.json` to modify the corresponding menuconfig options.

**Flash**

```bash
idf.py flash
```

> [!NOTE]
> To enter download mode: Long press the reset button (about 3 seconds) until the internal indicator light turns green, then release the button.
